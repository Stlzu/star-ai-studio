# DataForge — Web Scraping &amp; Data Extraction

**Web scraping service.** Turn any website into clean, structured CSV or Excel data.

## What I Do

I build custom scrapers for any publicly available website. Whether it's protected by Cloudflare, requires login, or uses infinite scroll — I handle it.

| Category | Examples |
|----------|----------|
| **Real Estate** | PropertyGuru, 99.co — prices, floor area, MRT distance |
| **E-Commerce** | Product prices, stock levels, reviews |

| **Market Research** | Competitor pricing, catalog data |
| **Lead Generation** | B2B contact data from directories |
